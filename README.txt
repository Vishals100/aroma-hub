AromaHub storefront — editable HTML, CSS and JavaScript website.

PROJECT FILES
- index.html: homepage and product catalogue
- product-*.html: individual product detail pages
- style.css: shared layout, colours and responsive styles
- script.js: mobile navigation, loading screen, newsletter demo and footer year
- img/logo/: original logo asset (the header now uses a text wordmark so the full name is visible)
- img/products/: product photographs
- img/features/: feature illustrations

PRODUCT CATALOGUE
The three cardamom sizes are grouped on one page:
- Green Cardamom — 8mm
- Green Cardamom — 7–8mm
- Green Cardamom — 6–7mm

GOOGLE MAPS LOCATION
Search for PASTE_GOOGLE_MAPS_LINK_HERE in index.html and the product detail pages.
Replace it with your Google Maps share URL, including the https:// part.
The homepage has a store-location section immediately above the footer.

EDITING THE WEBSITE
1. Open this folder in Visual Studio Code.
2. Open index.html with Live Server to preview the homepage.
3. Edit product names and prices in index.html and the matching product page.
4. Edit colours and spacing in style.css.
5. Edit mobile menu and other interactions in script.js.

IMPORTANT
The prices are examples only. Update all prices, product descriptions, business details, email address and social links before the website goes live.
